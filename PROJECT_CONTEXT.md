# Job Application Tracker — Project Context

## 1. Project Overview

This is a personal portfolio project called **Job Application Tracker**.

It is a full-stack web application built from scratch to help users track job applications, manage their application information, search/filter applications, and view application statistics.

The project is primarily intended to demonstrate practical programming and web-development skills on GitHub.
